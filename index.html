01All tools

Pick the right tool for the job

Filter by task, then open the tool you need. Each one follows the same simple steps.

  • Merge PDF

    Join several PDFs into one file, in the order you choose.

  • Split PDF

    Pull out single pages or page ranges as separate PDFs.

  • Organize PDF

    Reorder, delete or add pages, then save a clean new file.

  • Rotate PDF

    Turn sideways or upside-down pages the right way up.

  • Scan to PDF

    Scan paper documents with your phone camera and save them as PDF.

  • Compress PDF

    Shrink large PDFs so they are easier to email and upload.

  • Repair PDF

    Try to recover content from damaged PDFs that won't open.

  • OCR PDF

    Turn scanned pages into text you can search and copy.

  • PDF to Word

    Turn a PDF into a Word document you can edit.

  • Word to PDF

    Save DOC and DOCX files as PDFs that look the same on any device.

  • PDF to Excel

    Move tables from a PDF into a spreadsheet you can work with.

  • JPG to PDF

    Combine photos and images into one tidy PDF.

  • PDF to JPG

    Save each page as an image, or pull out the images inside.

  • Edit PDF

    Add text, images and shapes to any page.

  • Add page numbers

    Number your pages and choose the position, size and style.

  • Add watermark

    Stamp text or a logo across pages to show ownership or status.

  • Sign PDF

    Sign a document yourself, or send it to others to sign.

  • Protect PDF

    Add a password so only the right people can open the file.

  • Unlock PDF

    Remove the password from a PDF you already have access to.

  • Redact PDF

    Permanently black out private text and images.

  • Summarize PDFAI

    Get the key points of a long document in a short summary.

  • Chat with PDFAI

    Ask questions and get answers based on what's in your file.

  • Translate PDFAI

    Translate a document and keep the layout as close as possible.

  • Create a workflow

    Chain tools together, like merge → compress → protect, and run them in one go.
