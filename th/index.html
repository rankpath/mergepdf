01เครื่องมือทั้งหมด

เลือกเครื่องมือให้ตรงกับงาน

เลือกหมวดงาน แล้วเปิดเครื่องมือที่ต้องการ ทุกเครื่องมือใช้ขั้นตอนง่ายๆ แบบเดียวกัน

  • รวม PDF

    รวมหลายไฟล์ PDF เป็นไฟล์เดียว เรียงลำดับได้ตามต้องการ

  • แยก PDF

    ดึงหน้าเดียวหรือช่วงหน้าที่ต้องการ ออกมาเป็นไฟล์ PDF แยก

  • จัดเรียงหน้า PDF

    สลับลำดับ ลบ หรือเพิ่มหน้า แล้วบันทึกเป็นไฟล์ใหม่ที่เรียบร้อย

  • หมุน PDF

    หมุนหน้าที่ตะแคงหรือกลับหัว ให้ตั้งตรงอ่านง่าย

  • สแกนเป็น PDF

    ใช้กล้องมือถือสแกนเอกสารกระดาษ แล้วบันทึกเป็น PDF

  • บีบอัด PDF

    ลดขนาดไฟล์ PDF ให้เล็กลง ส่งอีเมลและอัปโหลดได้ง่ายขึ้น

  • ซ่อม PDF

    ช่วยกู้เนื้อหาจากไฟล์ PDF ที่เสียหรือเปิดไม่ได้

  • OCR PDF

    แปลงหน้าที่สแกนมา ให้ค้นหาและคัดลอกข้อความได้

  • PDF เป็น Word

    แปลง PDF เป็นไฟล์ Word ที่แก้ไขต่อได้

  • Word เป็น PDF

    บันทึกไฟล์ DOC และ DOCX เป็น PDF ที่เปิดเครื่องไหนก็หน้าตาเหมือนเดิม

  • PDF เป็น Excel

    ย้ายตารางจาก PDF ไปเป็นสเปรดชีตที่ใช้งานต่อได้

  • JPG เป็น PDF

    รวมรูปถ่ายและรูปภาพหลายรูป เป็น PDF ไฟล์เดียวที่เรียบร้อย

  • PDF เป็น JPG

    บันทึกแต่ละหน้าเป็นรูปภาพ หรือดึงรูปที่อยู่ในไฟล์ออกมา

  • แก้ไข PDF

    เพิ่มข้อความ รูปภาพ และรูปทรงลงบนหน้าไหนก็ได้

  • ใส่เลขหน้า

    ใส่เลขหน้า เลือกตำแหน่ง ขนาด และรูปแบบได้เอง

  • ใส่ลายน้ำ

    ประทับข้อความหรือโลโก้ลงบนหน้า เพื่อบอกเจ้าของหรือสถานะเอกสาร

  • เซ็น PDF

    เซ็นเอกสารด้วยตัวเอง หรือส่งให้คนอื่นเซ็น

  • ใส่รหัส PDF

    ตั้งรหัสผ่าน ให้เปิดไฟล์ได้เฉพาะคนที่ควรเห็น

  • ปลดรหัส PDF

    เอารหัสผ่านออกจากไฟล์ PDF ที่คุณมีสิทธิ์เปิดอยู่แล้ว

  • ปิดทับข้อมูลลับ

    ปิดทับข้อความและรูปที่เป็นข้อมูลส่วนตัวแบบถาวร

  • สรุป PDFAI

    สรุปประเด็นสำคัญจากเอกสารยาวๆ ให้อ่านจบได้เร็วขึ้น

  • ถามตอบกับ PDFAI

    พิมพ์คำถาม แล้วได้คำตอบจากเนื้อหาในไฟล์ของคุณ

  • แปลภาษา PDFAI

    แปลเอกสารเป็นภาษาอื่น โดยคงรูปแบบหน้าให้ใกล้เคียงต้นฉบับ

  • สร้างเวิร์กโฟลว์

    ต่อหลายเครื่องมือเป็นชุดเดียว เช่น รวม → บีบอัด → ใส่รหัส แล้วสั่งทำงานในครั้งเดียว

02วิธีใช้งาน

เสร็จได้ใน 3 ขั้นตอน

  1. 01

    เลือกเครื่องมือ

    เลือกงานที่ต้องการ เช่น รวมไฟล์ บีบอัด หรือแปลงไฟล์

  2. 02

    เพิ่มไฟล์

    ลากไฟล์มาวาง หรือเลือกไฟล์จากเครื่องของคุณ

  3. 03

    ดาวน์โหลดไฟล์

    ตรวจไฟล์ใหม่ แล้วกดบันทึก เท่านี้ก็เสร็จ

03ใช้งานแบบที่คุณถนัด

ใช้ได้ทุกที่ที่คุณทำงาน

เปิดในเบราว์เซอร์แล้วเริ่มได้เลย ไม่ต้องดาวน์โหลด ไม่ต้องตั้งค่า

บนคอมพิวเตอร์

เปิดเครื่องมือในเบราว์เซอร์ได้ทั้ง Windows, Mac และ Linux ไม่ต้องติดตั้งหรืออัปเดตโปรแกรม

บนมือถือ

เครื่องมือชุดเดียวกัน ออกแบบให้ใช้บนจอเล็กได้สะดวก สแกน เซ็น และส่งต่อได้จากมือถือ
